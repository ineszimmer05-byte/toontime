Datenschutzerklärung – ToonTime Uploader

Stand: Oktober 2026

1. Verantwortlich

ToonTime-DE, Kontakt: ines.zimmer05@gmail.com

2. Zweck der Anwendung

„ToonTime Uploader“ ist ein internes Werkzeug, das selbst produzierte Videos über die YouTube API Services auf den eigenen YouTube-Kanal ToonTime-DE hochlädt. Die Anwendung wird ausschließlich vom Kanal selbst genutzt.

3. Welche Daten verarbeitet werden

  • Ein OAuth-Zugriffstoken für das Google-Konto des Kanals ToonTime-DE, damit Videos hochgeladen werden können.
  • Die Kanal-ID und der Kanalname, um vor jedem Upload zu prüfen, dass der richtige Kanal verwendet wird.
  • Die hochgeladenen Videos samt Titel, Beschreibung und Schlagwörtern.

Es werden keine Daten von Zuschauerinnen und Zuschauern oder anderen Google-Nutzern erhoben.

4. Speicherung und Weitergabe

Das Zugriffstoken wird ausschließlich auf einem privaten, zugangsgeschützten Server gespeichert. Daten werden nicht verkauft und nicht an Dritte weitergegeben, außer an Google/YouTube, soweit das für den Upload technisch nötig ist.

5. YouTube API Services

Diese Anwendung nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

6. Widerruf

Der Zugriff kann jederzeit unter myaccount.google.com/permissions widerrufen werden. Auf Anfrage an die oben genannte E-Mail-Adresse werden gespeicherte Token gelöscht.
